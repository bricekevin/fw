Social Meter

Flash a fresh M5Stack Core Basic in about a minute. No toolchain, no source clone. It counts the followers on a platform you pick and shows the number on its screen.

What happens

  1. Plug your M5Stack Core Basic into a USB-C port on this computer. Use a data cable — a charge-only cable powers the device but carries no data.
  2. Press Connect & install and pick the device from the list. It usually appears as cu.usbserial-… or cu.SLAB_USBtoUART.
  3. Choose Install Social Meter, confirm the erase prompt, and wait about a minute. The first install writes the bootloader and the firmware together.
  4. When it reboots, follow the on-screen setup. Step 1 asks you to join the Social Meter-XXXXXX network from your phone; step 2 opens the setup page where you pick the platform, your handle, and a key if that platform needs one.

After the first install

It updates itself over Wi-Fi. Every six hours it checks for a newer build and installs it, rolling back on its own if one fails to start. You only need this page for a brand-new board or a recovery flash.
